# Talent Show (Forge 1.20.1)

## Сборка через GitHub (проще всего)
1. Создай пустой репозиторий на github.com.
2. Загрузи в него ВСЁ содержимое этой папки (включая скрытую `.github`).
3. Вкладка Actions -> Build mod -> дождись зелёной галочки (2-5 минут).
4. Открой запуск -> внизу Artifacts -> talentshow-jar -> скачай, внутри jar.
5. Положи jar в mods/ (и на клиент, и на сервер).

## Игра
Встань на ровное место лицом на юг: /talentshow build, потом /talentshow start.
Команды: start, stop, reload, build (оп), perform, do, rate.
Конфиги появятся в config/talentshow/ (боты, таланты, частушки, ai.json).
